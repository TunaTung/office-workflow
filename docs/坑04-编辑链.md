# 坑 04：Office 编辑链（aioffice 实测边界）

> 2026-08-14 实测。读取链把文档变 md 只是"看懂"，编辑源文件走 aioffice/officecli/x2t。

## 工具分工

| 工具 | 职责 | 实测 |
|---|---|---|
| aioffice | 快改主力：edit --ops（JSON+快照+乐观并发）、read/query/get、convert、template、diff、validate | ✅ |
| officecli | 备选 DOM：get/set(--prop)/move/swap/raw-set | ✅ |
| x2t（ONLYOFFICE） | 格式转换 + **渲染时计算公式** | ✅ |
| document-skills:docx | 保真：修订跟踪/批注/精确 XML（官方插件） | ✅ 修订删除+批注实测通（suggest_deletion / add_comment） |

## 实测边界（说清楚能/不能）

| 操作 | 状态 |
|---|---|
| xlsx 改单元格值（set） | ✅ `edit --ops set /'实验数据'/B2` |
| xlsx **move/add cell** | ❌ unsupported——挪表走 `read csv → create --from csv` 中转 |
| xlsx 结构级 add（sheet/table/chart/pivot） | ✅ |
| docx 改文字 / 加段落 | ✅（add 类型是 `p` 不是 `paragraph`） |
| 公式重算 | ⚠️ aioffice get 不算（type:blank）；**x2t 渲染时真算**（转 PDF 读文本验证） |
| 中文 sheet 名路径 | ⚠️ 必须引号 `/'实验数据'/B2`；--ops 内引号 `\u0027` 转义 |

## 核心经验

1. **编辑源文件 ≠ md 回写**：aioffice 直接 DOM 编辑，防降维副本覆盖
2. **快改/保真分层**：挪表改数据用 aioffice（快）；修订/批注/合同类用 XML 手术（references/docx-methodology.md）
3. **公式验证闭环**：写公式 → x2t 转 PDF → 读 PDF 文本核对结果（aioffice 不算，别依赖 cachedValue）
4. **自动快照**：aioffice edit 每次改自动存前 20 份，`snapshot restore` 可回滚——大胆改
